# 🔢 Fixed Code Naming & Photo Labeling Guide (固定代号命名指南)

You do **NOT** need to use specific building names! You can use simple, fixed code numbers for ANY building or topic!

---

## 🏷️ Fixed Code Naming Formula (固定代号公式)

### `b<Building_No>_p<Pin_No>_<Photo_No>.jpg`

- `b1` = Building 1 (建筑 1 / 题目 1)
- `b2` = Building 2 (建筑 2 / 题目 2)
- `b3` = Building 3 (建筑 3 / 题目 3)
- `p1` = Pin 1 (第 1 个标记点)
- `p2` = Pin 2 (第 2 个标记点)
- `p3` = Pin 3 (第 3 个标记点)
- `_1`, `_2`, `_3` = Photo 1, Photo 2, Photo 3 (第几张照片)
